# Atividade 1 - HTML, CSS e JS

Projeto desenvolvido como atividade prática de Git/GitHub.

## Estrutura do projeto

- `index.html` — página principal
- `style.css` — estilos da página
- `script.js` — interatividade da página
- `erro.txt` — arquivo de log/erros
- `img/` — pasta com as imagens utilizadas no HTML

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## Objetivo

Praticar o uso de repositórios Git/GitHub: commits, versionamento,
criação/alteração/exclusão de arquivos e organização de projeto web.
